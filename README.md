# 3TBTV — النسخة النهائية الأولية v2.0

موقع عربي متجاوب لمكتبة المحتوى، يتضمن:
- الصفحة الرئيسية والبحث والتصنيفات.
- صفحة تفاصيل المسلسل وقائمة المواسم والحلقات.
- مشغل فيديو داخل الموقع.
- لوحة إدارة على `/paneladmin`.
- إضافة المسلسلات والأغلفة والحلقات، وحذف المسلسل مع حلقاته.
- كلمة مرور مؤقتة مع فرض تغييرها عند أول دخول.

هذا المشروع لا يتضمن مسلسلات أو روابط بث جاهزة. انشر فقط الفيديوهات التي تملك حقوقها أو ترخيصًا لعرضها.

## المتطلبات
- Node.js 20 أو أحدث.
- مساحة تخزين كافية للفيديوهات.

## تشغيله على Windows
1. فك ضغط ZIP.
2. ثبّت Node.js من https://nodejs.org/
3. افتح CMD أو Terminal داخل مجلد المشروع.
4. شغّل:
   ```bash
   npm install
   npm start
   ```
5. افتح الموقع: http://localhost:3000
6. افتح لوحة الإدارة: http://localhost:3000/paneladmin

## الدخول الأول
- اسم المستخدم: `abo3tb`
- كلمة المرور المؤقتة: `1212as`
- عند أول دخول سيطلب تغييرها إلى كلمة مرور لا تقل عن 10 أحرف.

## ملفات البيانات
- قاعدة البيانات: `data/3tbtv.sqlite`
- الفيديوهات والأغلفة: `uploads/`

احتفظ بنسخة احتياطية من المجلدين `data` و`uploads`.

## قبل نشره على الإنترنت
هذه نسخة أولية وليست إعدادًا إنتاجيًا نهائيًا. قبل النشر:
- اضبط `SESSION_SECRET` على قيمة سرية عشوائية طويلة.
- شغّل HTTPS واضبط `NODE_ENV=production`.
- استخدم تخزين فيديو أو CDN عند وجود جمهور كبير.
- أضف تحديدًا لمحاولات تسجيل الدخول وفحصًا للملفات وحدودًا مناسبة للرفع.
- لا تستخدم كلمة المرور الافتراضية بعد أول دخول، ولا تشارك لوحة الإدارة علنًا دون حماية مناسبة.
